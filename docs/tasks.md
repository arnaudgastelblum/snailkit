# Tasks

![Tasks](../assets/scenes/tasks.webp)

Write a task where it comes up, and find it again in one place. You never have to choose between
the two.

## The idea

- **Write them anywhere.** In a meeting note, a project, today's daily note: `- [ ] Send the quote #client`.
  The tag says what it belongs to. The **Tags** tool suggests it as you type.
- **Find them all.** The **Tasks** tab of the Workbench gathers every tagged task of your vault in
  one list, grouped by tag, with **Today** and **Upcoming** views.
- **Handle them from there.** Check, prioritize, give a date, rename or move a task to another
  tag: the note is updated for you. Add one in a few keystrokes: `Call the bank !1 @tomorrow`.
- **Develop them.** Each task can have its own note: write in the **Note** area of its details
  and the note is created, linked from the task line with a small 📝. Long texts, images, links:
  open it as a normal note with the arrow.

## Good to know

- Open the list from the ribbon, the Note menu or Home. Right click a task for every action.
- Keyboard: `↑` `↓` to move, `X` to check, `T` for today, `N` for a new task.
- **Today** shows today's tasks first. Those from earlier days wait quietly below, folded, with
  **All to today**, **All to tomorrow** or **Remove dates** to settle them in one go (one Undo
  for all). Prefer the overdue ones first? **Show overdue first** in the settings.
- Nothing is stored apart: everything is plain Markdown in your notes, readable by other tools.
