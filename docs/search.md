# Search

![Search](../assets/scenes/search.webp)

Find a note, a task or a tag in a few letters. Search also looks inside your notes.

## Try it

1. Turn on **Search** and run **Snailkit: Search**, or type in Home's search field.
2. Type a few words and choose a result to open it.

## Good to know

- Add `#project/site ` or `in:design ` to narrow your search by tag or domain.
- Choose **All**, **Notes**, **Tasks** or **Brainstorms** to focus the results.
- When no note matches your words, **Create note** lets you start one.
