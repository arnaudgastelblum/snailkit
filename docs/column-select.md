# Column select

![Column select](../assets/scenes/column-select.webp)

Edit several lines at once. Select a column of text and type the change just once.

## Try it

1. In editing mode, hold `Alt+Shift` and press the arrows to select a rectangle, or use `Alt+drag`.
2. Type to replace every selected row, or paste a list with one item per row.

## Good to know

- Use `Alt+click` to add or remove individual cursors.
- You can select past short lines; typing fills the gaps with spaces.
- Press Escape to keep only the main cursor.
- Column gestures work on computers.
